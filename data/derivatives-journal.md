# Журнал базисных пар (DERIVATIVES RADAR)

Агент **читает** этот файл в начале отчёта и **перезаписывает** в конце.
Вы правите вручную только если вошли иначе / не вошли / другой N.

## Параметры счёта
См. `data/derivatives-account.json` (deposit_rub, max_go_share).

Статусы строки:
- `PLAN` — утренняя «рабочая сделка дня», ещё не подтверждена вами
- `OPEN` — позиция считается открытой (вы вошли или оставили PLAN без правки «не входил»)
- `REDUCE` — рекомендовано сократить, ждём факта
- `CLOSED` — закрыта (переносится в HISTORY)

## Правила агента (кратко)
1. Не выдумывать OPEN, которых нет в файле (кроме перевода сегодняшнего PLAN→OPEN по правилу слота).
2. Утро: пересчёт всех OPEN; одна новая PLAN; обновить файл.
3. Вечер: пересчёт OPEN+PLAN утра; вердикт ДЕРЖАТЬ/ВЫХОДИТЬ/СОКРАТИТЬ; обновить файл.
4. После ВЫХОДИТЬ → строка в HISTORY, убрать из OPEN.
