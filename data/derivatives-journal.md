# Журнал базисных пар (DERIVATIVES RADAR)

Агент **читает** этот файл в начале отчёта и **перезаписывает** в конце.
Вы правите вручную только если вошли иначе / не вошли / другой N.
ГО в журнале нет — размер позиции и маржу считаете вы.

## Параметры
См. `data/derivatives-account.json` (`max_core_pairs`).

Статусы:
- `PLAN` — пара из утреннего/вечернего **ЯДРА**, ещё не подтверждена
- `OPEN` — считаете открытой
- `REDUCE` — рекомендовано сократить
- `CLOSED` — в HISTORY

overnight: `day-only` | `ok-overnight`  
N — ориентир лотности 1:1 по ногам (вы можете взять другой N).

## Правила агента
1. ГО не считать и сделки из-за ГО не отбрасывать.
2. Показывать все ПРОВЕРЕННЫЕ пары; отдельно выбрать ЯДРО.
3. Утро/вечер: пересчёт OPEN/PLAN → ДЕРЖАТЬ/ВЫХОДИТЬ; обновить файл.
4. После ВЫХОДИТЬ → HISTORY.
