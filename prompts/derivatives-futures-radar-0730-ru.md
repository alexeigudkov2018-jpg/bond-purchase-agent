0. ПРАВИЛО БАЗИСА / КОНТАНГО / БЭКВОРДАЦИИ
════════════════════════════════════
1) Выровняй единицы спота и фьючерса (scale) ДО вычитания.
   Типичные ISS-случаи:
   - USD000UTSTOM ↔ Si*: Si/1000 ≈ USD/RUB
   - CNYRUB_TOM ↔ CR*
   - IMOEX ↔ MX*: MX/100 ≈ пункты индекса
   - RGBI ↔ RB* / RGBIF: часто settle/100
   - Акция TQBR ↔ фьючерс: проверь LOTVOLUME (часто ×100) или вечный *F (1:1)
   - Золото/серебро: НЕ вычитай сырой $/oz из ₽/г.
     GD_в_₽/г = CLOSE(GD*) × CLOSE(USD000UTSTOM) / 31,1034768
     базис_₽/г = GD_в_₽/г − CLOSE(RUGOLD); базис_% = (GD_в_₽/г / RUGOLD − 1)×100
     Серебро — то же с SV* и RUSILVER (см. prompts/finradar-metal-basis-ru.md / engine/rules.py).
   - Крипта Мосбиржи: спота BTC/ETH в ISS обычно нет → только календарь near↔far и/или вечный (*USDF) ↔ dated.
     Внешний спот (Binance и т.п.) — только с пометкой [B] и временем; по умолчанию не использовать.
2) базис = фьючерс_в_единицах_спота − спот
   базис_% = (фьючерс_в_ед_спота / спот − 1)×100
3) Режим:
   - базис > 0 → КОНТАНГО
   - базис < 0 → БЭКВОРДАЦИЯ
   - |базис_%| мал относительно своих 5/20 сессий → НЕЙТРАЛЬНО
4) Календарь: базис = far − near; far>near → календарное контанго; far<near → бэквордация.
5) Запрещено писать «базис н/д» / «контанго н/д», если обе ноги CLOSE есть — сначала выровняй scale.
6) Каркас пары:
   - КОНТАНГО → ЛОНГ дешёвой ноги (спот / near / perp) + ШОРТ дорогой (фьючерс / far / dated)
   - БЭКВОРДАЦИЯ → ЛОНГ дешёвой срочной + ШОРТ дорогой спотовой / near
7) Фиксация прибыли и выход (обязательно писать в каждом детальном разборе):
   - Фиксировать ТОЛЬКО закрытием ОБЕИХ ног разом (встречные ордера, то же N).
   - Цель: базис сжался к своему обычному окну (медиана 5–20с) или к заранее названному уровню.
   - Стоп: базис расширился против входа на ваш порог.
   - Календарный край: закрыть за несколько дней до экспирации near-ноги; не держать до поставки/экспирации без нужды.
   - Одна закрытая нога = уже не базисная сделка.

1. ПОЛНЫЙ СКАН FORTS (обязательно)
════════════════════════════════════
Источник: ISS engines/futures/markets/forts (доска RFUD).
1) Сними все securities: SECID, ASSETCODE, SHORTNAME, LASTTRADEDATE, OPENPOSITION/PREVOPENPOSITION, SETTLE/CLOSE, LOTVOLUME, INITIALMARGIN если есть.
2) Сгруппируй по ASSETCODE. Near = ближайшая экспирация с торгами; far = следующая. Вечные (*F, *USDF) отмечай отдельно.
3) Фильтр ликвидности (иначе не ранжируй):
   - Обычные: ОИ near ≥ 1 000 ИЛИ VALUE ≥ 50 млн ₽ за день
   - Крипта: ОИ ≥ 100 ИЛИ VALUE ≥ 5 млн ₽
   - Тонкие — только в блок «качество», не в топ.
4) Класс актива (обязательная колонка):
   - процентные ставки / долг (RGBI, RGBIF, RUONIA и аналоги)
   - FX (Si, CNY, Eu, …)
   - товары / металлы / энергоносители (GOLD, SILV, BR, NG, …)
   - индекс (MIX, RTS, RVI, …)
   - акции (SBRF/SBER, GAZR/GAZP, LKOH, ROSN, … + все TQBR-пары)
   - крипта (BTC, ETH, BTCUSDF, ETHUSDF, COINF, …)
   - прочее
5) В шапке скана: «просканировано N активов FORTS, в фильтр прошло M».

Таблица скана (компактно; можно топ внутри класса + хвост «ещё K»):
| Класс | ASSETCODE | Near | Far | Спот SECID | Базис_% | Режим | ОИ near | Δ базиса 1с |

Для акций: сопоставь фьючерс с TQBR (SBER↔SR*/SBERF, GAZP↔GZ*/GAZPF, LKOH, ROSN, GMKN, NVTK, MGNT, MOEX, VTBR, TATN, PLZL, ALRS, … — все ликвидные пары, где есть CLOSE спота).
Для ставок: RGBI спот + RB*/RGBIF; рядом сдвиг КБД 2г/10г и RUSFAR одной строкой (факт, не прогноз).
Для товаров: металлы по формуле ₽/г; нефть/газ — базис near/far и к доступному спот-прокси ISS, если есть.
Для крипты: календарь + perp↔dated обязательны.

2. РЕЙТИНГ ЛУЧШИХ СДЕЛОК
════════════════════════════════════
Кандидаты — только пары из скана с двумя SECID и прошедшим фильтром.

Скор (чем выше — тем лучше для рейтинга; это НЕ прогноз цены актива):

ликвидность_балл: 1.0 верхний квартиль ОИ скана, 0.5 медиана, 0.2 низ (выше фильтра).

Выведи:
A) ТОП-10 лучших пар:
| # | Класс | Score | Режим | ЛОНГ (SECID) | ШОРТ (SECID) | Базис_% | Δ1с | ОИ | Почему здесь лучше |
B) Лучшая в каждом классе (1 строка): акции / товары / крипта / ставки / FX / индекс (если класс пуст — «нет ликвидных»).

`Лучшая сделка дня: ЛОНГ: <SECID> | ШОРТ: <SECID> · <класс> · <режим> · базис_% … · score …`

### 3.x <Класс> · <ASSETCODE> · <режим>
