# FINRADAR · базис золота/серебра (правило)

Источник кода: `engine/rules.py` — `gold_basis` / `silver_basis` / `metal_basis_*`.

## Единицы

| Инструмент | ISS | Единица |
|---|---|---|
| RUGOLD | index | **₽ / грамм** (индекс по сделкам GLDRUB_TOM) |
| GLDRUB_TOM | CETS | **₽ / грамм** (контроль спота) |
| GD* (напр. GDZ6) | FORTS | **USD / тройская унция** |
| RUSILVER | index | **₽ / грамм** |
| SV* | FORTS | **USD / тройская унция** |
| USD000UTSTOM | CETS | USD/RUB |

Тройская унция: **31,1034768 г** (`TROY_OUNCE_GRAMS`).

## Формула (обязательно в блоке B3)

```
GD_в_₽/г = CLOSE(GD*) × CLOSE(USD000UTSTOM) / 31,1034768
базис_₽/г = GD_в_₽/г − CLOSE(RUGOLD)
базис_%   = (GD_в_₽/г / CLOSE(RUGOLD) − 1) × 100
```

Знак: **базис > 0** → срочный рынок дороже рублёвого спот-индекса = **контанго**; **< 0** → дешевле = **бэквордация**.

Серебро — та же схема с SV* и RUSILVER.

Парные ноги (только блок B7 утреннего FINRADAR): контанго → шорт GD* + лонг RUGOLD (ставка на сжатие); бэквордация → лонг GD* + шорт RUGOLD. Не путать с односторонним направлением металла.

## Как писать в отчёте

Одной строкой с TRADEDATE всех трёх ног (GD, USD, RUGOLD), плюс базис ₽/г и %.
Пример: `GDZ6→₽/г = …; базис к RUGOLD = +230 ₽/г (+2,2%)`.
Без перевода валюты/унции→грамм писать «базис н/д» **запрещено**, если все три CLOSE есть.

Опционально рядом: базис GD к **GLDRUB_TOM** той же датой (тоже ₽/г).
