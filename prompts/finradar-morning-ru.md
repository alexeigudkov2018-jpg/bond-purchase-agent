B6a. Полный скан FORTS (обязательно каждый отчёт)

Алгоритм скана (ISS):
1) Сними список securities FORTS на дату сессии (ASSETCODE, SECID, LASTTRADEDATE, PREVOPENPOSITION / OPENPOSITION).
2) Сгруппируй по ASSETCODE. Внутри группы возьми near = ближайшая экспирация с торгами, far = следующая.
3) Фильтр ликвидности (иначе строку в рейтинг не ставь):

   - для крипты порог мягче: ОИ ≥ 100 ИЛИ VALUE ≥ 5 млн ₽;
   - VALUE=0 и ОИ<порога → в C как «тонкий», в B7/B8 не ранжируй.
4) Класс актива помечай: FX / ставка-долг / металл / нефть-газ / индекс / акция / крипта / прочее.
5) Для КАЖДОГО прошедшего фильтр ASSETCODE посчитай:
   - календарный базис far−near + режим;
   - если есть спот на Мосбирже (TQBR акция, CETS валюта, индекс SNDX/INPF, металл-индекс) — базис фьючерс−спот после scale;

   | Класс | ASSETCODE | Near SECID | Far SECID | Спот SECID | Базис_% | Режим | ОИ near | Δ базиса 1с |
   В шапке таблицы: «просканировано N активов FORTS, в фильтр ликвидности прошло M».

Для каждой пары (спот↔фьюч и/или near↔far):
1) Факт: актив, класс, ноги (SECID), scale, базис, базис_%, режим, базис вчера, сдвиг базиса за 1/5 сессий, ОИ/VALUE.
2) Каркас пары (механически по знаку):
   - КОНТАНГО (срочный богаче спота / far богаче near):
     идея сжатия базиса → ШОРТ дорогой ноги (фьючерс / far) + ЛОНГ дешёвой ноги (спот / near)
     классика: cash-and-carry / short calendar
   - БЭКВОРДАЦИЯ (срочный дешевле спота / far дешевле near):
     идея расширения к справедливой / схождения вверх → ЛОНГ дешёвой срочной ноги + ШОРТ дорогой спотовой / near
     классика: reverse cash-and-carry / long calendar
   - НЕЙТРАЛЬНО: «пары нет — базис внутри своего окна; не раздувать»
3) Формат строки (жёсткий шаблон):
   | Класс | Актив | Режим | ЛОНГ (SECID) | ШОРТ (SECID) | Базис_% | Δ1с | ОИ | Зачем | Риск |
   Дословно в строке или под таблицей:
   `ЛОНГ: <SECID>  |  ШОРТ: <SECID>`
   Примеры:
   - `ЛОНГ: USD000UTSTOM  |  ШОРТ: SiZ6`
   - `ЛОНГ: SBER  |  ШОРТ: SRZ6`
   - `ЛОНГ: RUGOLD  |  ШОРТ: GDZ6`
   - `ЛОНГ: BTX6  |  ШОРТ: BTZ6`   (крипто-календарь)
   - `ЛОНГ: BTCUSDF  |  ШОРТ: BTZ6` (вечный vs датированный, если базис считает)
   Запрещены формулировки без кода: «лонг спот / шорт фьюч», «купить ближний».
4) Не предлагай голый односторонний вход («только шорт RBZ6» / «только лонг BTC»). Только две ноги одного актива — оба SECID.
5) Не смешивай разные активы в одну «пару» (нельзя SiZ6 vs GDZ6; нельзя BTC vs ETH как базисная пара).
6) Если спот-нога недоступна (нет шорта индекса/крипто-спота на счёте) — явно:
   `спот-нога недоступна → календарь` и `ЛОНГ: <near SECID>  |  ШОРТ: <far SECID>` (или наоборот по знаку).
7) Без слов «гарантированный заработок». Пиши: «ставка на сжатие/расширение базиса», ГО, комиссии, FX, экспирация, для крипты — риск вечного финансирования/широкий спред.

B8. Лучшие сделки дня (рейтинг) — ОБЯЗАТЕЛЬНО
Собери кандидатов из B7 (все классы: акции, FX, металлы, индекс, долг, крипта, сырьё).
