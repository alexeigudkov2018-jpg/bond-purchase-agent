# Вторничный пакет облигаций

Агент каждый вторник собирает покупки на **170 000 ₽**: рублёвые фиксированные ОФЗ и корпоративные облигации рейтинга A− и выше. Продаж нет, плеча нет.

Правила взяты из сводки портфеля Альфа 2030 + SBER 2030 (18.09.2026, уточнение 22.09.2026).

- Нечётный месяц — SBER 2030, договор `4225FH3`: ОФЗ 35%, AAA/AA 32,5%, группа A с госучастием 32,5%.
- Чётный месяц — Альфа 2030, соглашение `5737728`: ОФЗ 65%, корпорат 35% — AAA/AA или группа A с госучастием.
- С 1 ноября 2026 группа A без госучастия в пакет не входит. Госучастие — по списку маркеров эмитента в `engine/rules.py`.
- ОФЗ: большой купон от 11%, погашение через 6,5–9,5 лет (окно с 27.10.2026 под продажу частями в 2030–2032).
- Корпораты AAA/AA — 4–7 лет; группа A — 2–5 лет. Короче четырёх лет AAA/AA попадают в список на согласование, а не в пакет.
- Ликвидность — **средний** дневной оборот за 10 сессий не ниже 5 млн ₽. Медиана скринера [ДОХОДЪ](https://www.dohod.ru/analytic/bonds) показывается отдельно и порог не заменяет.
- Вместо долга/EBITDA и покрытия процентов, которых в скринере нет, берутся «кредитное качество» и «качество эмитента». NetDebt/Equity в баллы не входит.
- Порог балла — 5 из 10. Комиссия резервируется как 0,3%, фактическая ставка Альфы 0,291%, Сбера 0,31%.

Это не индивидуальная инвестиционная рекомендация. Цифры предварительные, пока нет брокерского отчёта.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m engine
npm install
npm run dev
```

Интерфейс открывается на [http://127.0.0.1:4317](http://127.0.0.1:4317).

Повторить сборку из консоли: `python3 -m engine`. Свежие котировки и скринер: `python3 -m engine --refresh`.

Предварительный пакет по книгам ДОХОДЪ от 12 октября (без биржевого принта): `python3 -m engine.preview`. Книги лежат в `data/imports/`. Медиана оборота в этом расчёте порог ликвидности не закрывает.

Сверка этих же строк с Московской биржей: `python3 -m engine.moex_verify`. Цена, НКД, YTM, дюрация, средний оборот и график купонов берутся из ISS.

Чтобы сборка сама стартовала во вторник в 09:00 МСК (06:00 UTC):

```cron
0 6 * * 2 cd /path/to/repo && python3 -m engine --refresh
```

## Вводные

Файл `data/inputs.json`: взнос, купоны на счёте Альфы или Сбера, оценка портфеля, ISIN прошлой недели. Пустая оценка означает, что порог 15 млн ₽ не проверен и платёж идёт на обычный счёт. До конца 2026 регулярные покупки на обычном счёте даже после порога.

Локальный CSV в `data/screener/` может дополнить коэффициенты колонками `isin,net_debt_ebitda,ebitda_interest,credit_quality,issuer_quality`.

## Регрессивная наценка

Отдельный калькулятор для ассортимента (~100 000 SKU, закупка 1–180 000 ₽): дешёвые позиции получают высокую наценку, дорогие — низкую. Цель — валовая маржа **23–27% по деньгам**, не среднее наценки.

- 1–5 ₽ — до 1000%
- 50–100 ₽ — 280–350%
- 180 000 ₽ — 25% наценки (= 20% маржи)
- 500–100 000 ₽ — мягкий спуск многими ступенями

Интерфейс: [http://127.0.0.1:4317/markup](http://127.0.0.1:4317/markup).

```bash
python3 -m engine.markup 100
python3 -m engine.markup --schedule
python3 -m engine.markup --csv catalog.csv
```
